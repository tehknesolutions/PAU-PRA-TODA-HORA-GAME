# CANON E AUTORIDADE

## Regra principal

**PAU PRA TODA OBRA é soberano sobre si mesmo.**

Nenhum outro repo, chat, projeto ou framework assume autoridade automática sobre este jogo.

## Estados documentais

### APROVADO
Decisão explicitamente aceita no Discovery. Pode orientar produto e implementação.

### DERIVADO
Consequência lógica/recomendação produzida a partir de decisões aprovadas. Deve permanecer identificada como derivada até validação quando alterar significativamente o produto.

### REFERÊNCIA
Conhecimento consultado em Taijifu, HNK, TEHKNÉ, outros projetos, jogos ou fontes externas. Não entra automaticamente no jogo.

### TBD
Questão ainda não especificada: fórmula, número, conteúdo, balanceamento, arquitetura ou decisão futura.

## Pipeline de reaproveitamento

`CONSULTAR → IDENTIFICAR KNOW-HOW → AVALIAR → ADAPTAR → PROPOR → APROVAR → INCORPORAR`

## Regra de não contaminação

`CONSULTAR ≠ IMPORTAR ≠ APROVAR ≠ CANONIZAR`

## Taijifu

Taijifu é uma fonte marcial relevante do ecossistema HNK e pode ser consultada para técnicas, capacidades, integração, pedagogia e conhecimento marcial. Isso não torna o currículo Taijifu automaticamente parte das regras deste jogo.

## Implementação

Código não deve canonizar silenciosamente uma hipótese de design. Decisões ainda TBD devem permanecer configuráveis, experimentais ou documentadas como tal até aprovação.
